- Set `texture.anisotropy = 8` for better quality at oblique viewing angles
- Render a `<group>` with position and rotation containing:

    - Right: position [w/2 + fw/2, 0, WALL_OFFSET], size [fw, h, FRAME_DEPTH]
  - All frame meshes use `meshStandardMaterial` with FRAME_COLOR

Where w=displayWidth, h=displayHeight, fw=FRAME_WIDTH.

Do NOT use `any` types. Export the component as a named export.
